# Security Policy

AdaptNXT takes security and video stream privacy seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities or stream authorization bypass flaws privately by emailing:
📧 **queries@adaptnxt.com** with the subject line `[SECURITY] Jetson YOLO RTSP Pipeline Vulnerability`.

We will respond within 48 hours and work with you to coordinate a responsible patch release.
